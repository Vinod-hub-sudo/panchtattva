# PanchTattva

Progressive Web App (PWA) for World Clock, Solar & Night Arc Tracking, Drik Ganita Panchangam, Jyothishyam & Kundali, Sacred Temples, Local Sightseeing, and Festivals.

## Root Files
- `index.html` — Main app shell and 6-tab UI
- `app.css` — Styling and solar/lunar arc styles
- `app.js` — Clocks, night/lunar tracker, Panchangam, Kundali, temples, sightseeing, and festivals logic
- `temples.json`, `corridor-trains.json`, `corridor-buses.json` — App datasets
- `.github/workflows/deploy.yml` — Automated validation and GitHub Pages workflow
